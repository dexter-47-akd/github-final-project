# Simple Interest Calculator

A simple tool to calculate the **simple interest** on a principal amount over a given period of time.

## Formula

The simple interest is calculated using the formula:

```
I = (P × R × T) / 100
```

Where:

| Symbol | Description              | Unit              |
|--------|--------------------------|-------------------|
| **I**  | Simple Interest          | Currency          |
| **P**  | Principal amount         | Currency          |
| **R**  | Rate of interest         | Percentage per year (%) |
| **T**  | Time period              | Years             |

The total amount payable after the time period is:

```
A = P + I
```

## Example

If you invest:

- **Principal (P):** ₹10,000
- **Rate (R):** 5% per annum
- **Time (T):** 2 years

Then:

```
I = (10000 × 5 × 2) / 100 = ₹1,000
A = 10000 + 1000 = ₹11,000
```

So, the simple interest earned is **₹1,000** and the total amount is **₹11,000**.

## Features

- Calculate simple interest from principal, rate, and time
- Compute total amount (principal + interest)
- Easy-to-understand formula and examples

## How to Use

1. Enter the principal amount (`P`).
2. Enter the annual rate of interest (`R`) in percent.
3. Enter the time period (`T`) in years.
4. Apply the formula `I = (P × R × T) / 100` to get the interest.
5. Add the interest to the principal to get the total amount `A = P + I`.
